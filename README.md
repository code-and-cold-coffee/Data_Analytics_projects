**Lahore Fast Food Sales Analysis**

A beginner Pandas project analysing weekly restaurant sales data.

**.Features**
.Total weekly revenue calculation
.Revenue analysis by item
.Super Hit item classification
.Average ratings per item
.Revenue analysis by day
.Data visualisation using Matplotlib
.Statistical summary using Pandas

**-Libraries Used**
.Pandas
.NumPy
.Matplotlib
**.Key Insights**
___Burger has the highest average rating._
__Pizza generates the highest revenue._
__Wednesday records the highest revenue._
__Products with sales above 100 units are classified as Super Hit_.__
